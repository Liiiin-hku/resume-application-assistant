# 使用说明

## 安装一次，以后直接用

使用 Chromium 内核 151 或更新版本的 Edge / Chrome（本机 Edge 为 152）。打开 Edge，地址栏输入 `edge://extensions`；Chrome 为 `chrome://extensions`。开启“开发者模式”，选择“加载解压缩的扩展”，定位到：

```text
E:\Codex_Projects\简历网申投递助手\dist\extension
```

选择文件夹，里面应当直接看到 `manifest.json`。在浏览器工具栏的扩展菜单里把“简历网申投递助手”固定。先打开一个普通网页，再点击插件图标打开侧栏。也可从扩展详情的“扩展选项”打开宽屏资料编辑器。

插件日常使用无需开终端、运行 Codex、配置 API 或启动调试浏览器。开发者模式中的未打包扩展可能提示由你自行安装，这是本地开发安装方式。

## 导入、核对和补齐资料

在“① 资料库”选择 PDF 或 DOCX。插件实际提取文字后才进入待确认区。扫描件或纯图片 PDF 无可用文字时会提示；加密、损坏、超过 20 MB 的文件会拒绝，提供粘贴或手填途径。最多处理 60 页 PDF；本版不含 OCR。

也可展开“粘贴简历文本”。解析偏保守，优先读取“姓名：…”“学校：…”“入学时间：…”等明确标签和唯一邮箱。无明确结构的排版简历可能只识别少量字段，**请对照临时显示的原文，在资料库补齐；提取文字成功不代表结构化字段齐全。** 未确认原文 / 导入草稿只在当前界面内存中，关闭页面前请完成确认或保留原件。

待确认区逐项显示来源、新值和旧值。每组可选“新增记录”或更新现有经历。重新导入不会静默覆盖已确认事实；特别检查本科与硕士的合并目标。勾选你核对过的字段，点“接受勾选字段并确认真实”。未勾选字段不进入默认资料库。

资料库可新增基本信息、教育、实习工作、项目科研、技能、语言、证书、奖项、自我评价问答和求职信息。每条经历有内部稳定 ID，修改标题不会改变 ID。展开一条记录，修改值，逐项勾“事实已确认”，最后点“保存资料”。编辑某值会取消它的确认状态。

请保留实际日期精度：仅知道年份就填年份，“至今”“预计毕业”保留原意。只知道年月时，网页要求完整日期，插件会请你人工确认，不补日期。学历与学位分开；籍贯、出生地、户籍地、现居地分开。薪资、到岗时间、工作授权、调剂等由你主动补充。政治面貌、出生日期和工作授权的自动填写还需本次单独确认。证件、健康等更敏感字段在网站人工填写；不要放进自由文本或 JSON 中。

## 打开岗位、扫描和填写

1. 粘贴完整 HTTP/HTTPS 岗位链接并打开，或直接打开你已有的网申标签页。
2. 自己登录、收验证码和进入表单。插件不能代替登录，也不会越过验证码。
3. **在目标标签页点击工具栏插件图标**。这个动作给当前页面临时访问权限。仅打开新标签页不授予访问权限；跨域跳转后再点一次图标。
4. 点击“扫描当前页面”。默认“只扫描，不写入”开启，预览期间不向网页输入真实资料。
5. 核对预览中的字段、资料来源、匹配依据和状态。多条经历请展开分组关联，选择本科、硕士或对应项目；不能只相信页面顺序。
6. 低确定性项默认不勾选。已有网页内容默认保留；如确需覆盖，先核对原值与新值，单独确认“允许覆盖”，再勾选该字段。
7. 关闭“只扫描”，点“确认填写勾选项”，阅读网站自动保存提示并确认。
8. 检查结果。下一页由你手动进入，再重新扫描。页面跳转、其他网页标签切换、结构变化或后台重启后，旧计划失效。

额外站点权限并非必需。若确需保留某站点访问授权，可展开“按需保存本站访问授权”，在岗位链接框填完整 URL 并点击授权，在浏览器提示中接受。这只请求该来源；可以用“移除额外站点授权”撤销。不处理浏览器设置页、扩展商店、明显银行支付页面等。

## 看懂状态与处理例外

| 状态 | 含义与处理 |
| --- | --- |
| 待填写 | 已确认事实、明确映射、格式可用，等待你确认 |
| 已写入并验证 | 控件值在有限观察窗口稳定且未报告校验错误；还需你最终检查，不能代表服务器已保存 |
| 已跳过 | 已有内容或禁止自动处理的字段；需要时人工操作 |
| 缺少资料 | 到资料库补充真实信息，保存后重扫 |
| 待确认 | 记录对应、规则、格式、敏感字段或自定义控件需要你处理 |
| 填写失败 | 网站拒绝、回退、校验未通过、结构改变等；阅读原因，可只重试失败项 |

暂停停止发送后续字段，正在处理的一项会完成核验；“继续”恢复。取消终止剩余批次，已经输入的值不会自动清除。重新扫描会清空本次撤销记录。失败项若已有不同内容，请重新扫描差异后操作，不盲目重试。

“撤销本次本地修改”只尝试恢复本插件写入且随后值未被改动的字段，不覆盖你后来改的内容。原来完全未选的单选组无法通过正常交互可靠恢复为空，会跳过并请你人工处理。**撤销本地值不能撤回网站收到或自动保存的数据。**

未识别字段可展开“手动字段关联与复制”，指定它对应资料库哪一字段；可保存本站关系，仅应用于同一来源、路径和字段结构。规则不包含你的实际资料值。复杂学校搜索、级联地址、自定义日期、iframe 和 Shadow DOM 暂不自动操作，复制资料后在网页手动选择实际选项。

插件不自动点“新增经历”。先在网站创建空白记录，再重新扫描与关联。附件上传和导入简历是两件事：请在网站原生文件选择器主动选择上传文件，插件不会凭 Windows 文件路径读取或上传文件，也不会假报上传成功。

## 备份、清空与更新

在资料库点“导出资料备份”，得到此插件的 JSON 文件。文件包含个人事实，请妥善保存；可自行放进项目 `data/private/`。备份当前不包含站点映射规则，换浏览器后需要重新关联。导入 JSON 仍经过待确认 / 差异流程。

浏览器数据与磁盘是两个位置：从 PDF 导入不意味着以后原件自动更新浏览器库，导出也不是自动同步。Edge 与 Chrome 的资料库彼此独立。卸载扩展会失去浏览器中的资料；重新加载同一扩展通常保留。

“清空本地资料”需要确认，会删除此插件的个人库及站点规则，不删除磁盘原件和导出备份。

更新步骤：先导出备份 → 双击根目录 `一键构建.cmd`（只有修改源码后需要）→ 等待明确成功提示 → 在扩展管理页点该插件“重新加载” → 刷新正在使用的网申页面并重新扫描。**保留同一个 dist/extension 目录，不要先卸载。** 公钥保存在 `src/extension-key.json`，构建不会重新生成已有公钥。

本版 schemaVersion 为 1。遇到不支持的未来格式会拒绝导入并保留旧库，维护者须先实现迁移和回归测试，不能强行降级覆盖。

## 先用虚构资料练习

`tests/fixtures/虚构示例资料.json`、`虚构简历.docx`、`fictional-text.pdf` 都是明确虚构的测试文件。示例 JSON 带 demo 标志，禁止与正式资料混合。PDF / DOCX 自身不带插件格式标志，练习前请使用空库，核对“虚构”字样，练习后清空再录入真实资料。

本地表单只供开发测试。需要复现问题时，让 Codex 在本项目运行测试入口；不要把真实简历、登录 Cookie、完整已填网页或未经脱敏截图放入测试或开发记忆。
