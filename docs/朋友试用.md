# 朋友试用：简历网申投递助手 0.1.0

这是个人网申自动填写辅助插件。仓库已公开，所有者授权大家读取、下载，并在自己的浏览器安装和使用。无需 GitHub 协作者权限、Node.js、终端、AI API 或自建账户。

## 下载与安装

1. [下载 v0.1.0 安装 ZIP](https://github.com/Liiiin-hku/resume-application-assistant/releases/download/v0.1.0/resume-application-assistant-v0.1.0.zip)。版本详情及 `SHA256SUMS.txt` 在 [Release 页面](https://github.com/Liiiin-hku/resume-application-assistant/releases/tag/v0.1.0)。不要下载页面下方的 Source code ZIP 来直接安装。
2. 把 ZIP 完整解压到自己长期保留的文件夹，例如 `D:\浏览器插件\简历网申投递助手`。目录位置可以自己选；不要直接在压缩包里打开。解压后应能看到 `manifest.json`、`panel.html` 等文件。
3. 优先使用 Microsoft Edge，在地址栏打开 `edge://extensions`，开启“开发者模式”，点击“加载解压缩的扩展”，选择**直接包含 manifest.json 的文件夹**。Chrome 对应 `chrome://extensions` → “加载已解压的扩展程序”。
4. 固定工具栏中的插件图标。在普通网页点击图标，打开侧栏进入“① 资料库”。遇到单位管理策略禁止加载时，需要由设备管理方处理；本插件不会修改系统策略。

本插件暂未上架 Edge / Chrome 扩展商店。安装包是可加载的构建结果，不需要先打开 Codex，也不需要每次运行终端。

安装包清单要求浏览器的 Chromium 内核版本至少为 151。旧版浏览器可能拒绝加载；本机已经验证的 Edge 版本为 152。不同朋友的浏览器仍需实际安装确认。

## 第一次测试

1. 先使用虚构文本了解流程。例如粘贴下面的示例，再逐项核对、确认；不要把示例当成个人正式资料。

   ```text
   姓名：示例用户
   手机：13800000000
   邮箱：demo@example.com
   以上均为虚构测试资料。
   ```

2. 了解界面后，在资料库中清空虚构数据并确认，再导入自己的文字 PDF、DOCX、文本或本插件 JSON。逐项核对资料来源和值，尤其教育经历、日期和成绩；未确认内容不用于默认填写。
3. 自己打开要申请的真实岗位、完成登录并进入表单，再点击该页面上的插件图标授权。新标签页或跨域跳转后可能需要重新点击。
4. 保持“只扫描”开启，检查预览里的本人 / 联系人字段、经历关联、日期、已有内容和缺失项。**扫描不会把简历值写进页面。**
5. 确认预览后关闭“只扫描”，选择需要的项目并确认填写。检查实际页面和填写结果；复杂选择器、附件、声明和最终提交自己完成。

网站可能在输入时自动保存：一旦确认填写，内容就可能被网站接收，不必等到最终提交。使用前可阅读 [完整使用说明](使用说明.md)。

## 建议反馈这些结果

- 是否能安装并打开侧栏；浏览器名称、完整版本号、插件版本。
- PDF / DOCX 是否提取出文字；需要手动修改的字段类型。不要公开上传真实简历原件。
- 当前岗位表单能否扫描；字段是否对应正确，已有非空内容是否得到保留。
- 确认填写后是否保持正确；哪些字段出现失败或回退，刷新 / 重扫后的现象。
- 是否存在本人 / 紧急联系人、不同学历 / 经历串用等问题。

可在 [GitHub Issues](https://github.com/Liiiin-hku/resume-application-assistant/issues) 提交反馈（需要登录 GitHub），或把脱敏结果交给维护者。反馈可按“浏览器和插件版本、复现步骤、预期、实际、是否能稳定复现”组织。截图先遮住姓名、联系方式、证件、已填经历和账户信息；网址移除含登录票据或其他个人参数的查询串。公开 Issue 不放个人库 JSON、Cookie、密码或 API Key。

## 当前测试范围

开发阶段已有 21 项单元测试、11 项真正加载扩展的 Chromium E2E 通过；本机 Edge 152 隔离加载与 DOCX 冒烟通过。2026-09-05 已另外验证仓库页面、Release 页面、源码和两个安装附件均可匿名访问，ZIP 与本地发布版本 SHA256 一致。

朋友的 Edge / Chrome 人工安装、具体系统差异和真实招聘网站仍需本轮试用验证。当前没有任何真实招聘平台的专属适配承诺；复杂自定义控件、iframe、Shadow DOM 和附件上传需要手动处理。插件不自动注册、登录、处理验证码、勾选声明、批量投递或最终提交。AI 本版未实现。

## 更新、资料与仓库权限

更新前在插件中导出个人库备份。保留原加载目录和扩展身份，把新版本内容解压到原位置，再到扩展管理页点击“重新加载”；不要先卸载。更完整的迁移说明见 [使用说明](使用说明.md)。插件不会自动从 GitHub 检查或安装更新。

每个人的资料只在各自浏览器的扩展本地存储中，不会因为安装相同插件而互相共享。普通本地存储不是加密保险箱；浏览器资料和磁盘上的导出备份也不自动同步。

访客可以读取、下载或 Fork 仓库，但没有向 `Liiiin-hku/resume-application-assistant` 直接推送、合并代码或删除文件的权限。Issue / Pull Request 反馈不等于获得原仓库写权限；是否接受更改由所有者决定。别人仍可修改自己下载或 Fork 的副本。

第三方组件的版权及许可说明保留在安装包内的 `THIRD_PARTY_NOTICES.txt`。
