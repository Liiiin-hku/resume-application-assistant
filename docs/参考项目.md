实际运行依赖：`pdfjs-dist 6.3.289`（Apache-2.0）本地 PDF 文本读取和本地 worker / CMaps / fonts；`mammoth 1.12.2`（BSD-2-Clause）DOCX `extractRawText`，不渲染其 HTML。依赖锁定在 pnpm-lock.yaml。间接依赖的版权和许可证由构建脚本从已安装包生成 `dist/extension/THIRD_PARTY_NOTICES.txt`；构建不会联网拉取运行代码。

官方技术依据：

- [activeTab 临时权限](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab)、[storage 与访问层级](https://developer.chrome.com/docs/extensions/reference/api/storage)：按用户动作访问网页，完整资料库限制在可信上下文。
- [Playwright 扩展测试](https://playwright.dev/docs/chrome-extensions)：使用捆绑 Chromium 和持久化上下文；不把自动化测试等同于用户 Edge / Chrome 人工验收。
- [CDP Extensions.triggerAction](https://chromedevtools.github.io/devtools-protocol/tot/Extensions/#method-triggerAction)：仅在隔离测试环境触发工具栏 action。测试启用专用扩展调试开关，交付插件和日常浏览器不依赖它。
- [PDF.js 示例](https://mozilla.github.io/pdf.js/examples/)、[Mammoth 官方仓库](https://github.com/mwilliamson/mammoth.js)：只提取文本，源文件内容不执行。
- [React 受控 input](https://react.dev/reference/react-dom/components/input)：以实际组件 state 与重新渲染校验事件效果；React / React DOM 19.2.8 仅用于本地回归 fixture，不进入插件包。
- [pnpm 设置](https://pnpm.io/settings)：pnpm 11 的普通项目设置使用 pnpm-workspace.yaml，本项目缓存目录为 .pnpm-store。
- 用户提供的 [AGENTS.md 官方入口](https://developers.openai.com/codex/agent-configuration/agents-md) 和 [Hooks 官方入口](https://developers.openai.com/codex/hooks) 当前分别重定向到 `learn.chatgpt.com/docs/agent-configuration/agents-md` 与 `learn.chatgpt.com/docs/hooks`。以实际获取的内容核对项目配置发现、事件和信任要求。
