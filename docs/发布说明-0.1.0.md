# 简历网申投递助手 0.1.0

个人使用的本地网申填写辅助插件。无需 AI API、服务器、云账户或常驻 Codex。

## 下载与安装

下载本 Release 的 `resume-application-assistant-v0.1.0.zip`，解压到长期保留的文件夹。在 Edge 的 `edge://extensions`（Chrome 为 `chrome://extensions`）开启开发者模式，加载解压后直接包含 `manifest.json` 的目录。

已经使用本地 `dist/extension` 的用户继续保留原加载目录。更新前导出个人库，更新后点“重新加载”，不要先卸载。插件不自动从 GitHub 检查或安装更新。

GitHub 自动生成的 Source code ZIP 是开发源码，需构建；上面的版本安装 ZIP 是可直接加载的构建结果。校验摘要见同页 `SHA256SUMS.txt`。

## 本版功能

- 本地解析文字 PDF、DOCX、粘贴文本、插件资料 JSON。
- 待确认事实、多条经历、来源、导入差异、编辑和备份。
- 当前页授权、扫描预览、原生字段匹配、手动关联及填写核验。
- 已有值保护、暂停取消、失败重试、有限撤销。
- 工程共享记忆及 checkpoint；项目 Hook 需要用户审阅信任，尚无真实触发验证。

## 实际验证与限制

Windows 类型检查、构建审计及 21 项单元测试通过；隔离 Chromium 的 11 项真正加载扩展 E2E 通过，包含真实 React 状态回归。本机 Edge 152 隔离加载与 DOCX 解析通过。

Edge / Chrome 人工安装和真实招聘网站待验证。复杂自定义控件、iframe、Shadow DOM、附件上传由用户手动处理。PDF 解析偏保守，复杂排版需核对，加密文件分支缺少真实样本回归。没有宣称特定招聘平台已适配。

不自动注册、登录、验证码、勾选声明、批量投递或最终提交。点击确认填写后，网站可能已经自动保存内容。

源码、中文文档、虚构测试、依赖锁文件和脱敏开发记忆在仓库；个人简历、浏览器资料库、凭据、依赖缓存、测试浏览器目录不上传。
